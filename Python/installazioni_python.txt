Installazione e autocompletamento Python in Visual Studio Code

1. Installare l'interprete Python da terminale: winget install 9NQ7512CXL7T

2. Trovare il percorso dov'è installato l'interprete:
  1. Aprire un terminale CMD / Prompt dei comandi, non Powershell
  2. Digitare innanzitutto cd\
  3. Subito dopo digitare dir/s python.exe
  4. Dopo un po' di tempo vengono mostrati vari percorsi dove sono installati i vari eseguibili di Python.
  5. Copiare soltanto il percorso simile a: C:\Users\nome.utente\AppData\Local\Python\pythoncore-3.14-64
  6. Per copiare va nei terminali premere Ctrl + Shift + C

3. Aprire il menu Windows e digitare "env" e selezionare "Modifica le variabili d'ambiente per l'account". ATTENZIONE, NON selezionate "per il sistema" perché servirebbero i permessi di amministratore.
  1. Nella finestra che si apre selezionare "Variabili d'ambiente..." fate doppio click su "Path"
  2. Nella tabella che si apre cliccare su "Nuovo" e incollare il percorso copiato in precedenza.
  3. Per sicurezza portare in cima alla lista la nuova voce selezionandola e cliccando su "Sposta su" più volte. Infine salvare ed uscire.

4. Aprire Visual Studio Code e installare l'estensione Python
5. Andare nelle impostazioni digitando Ctrl + ,
6. Nella barra di ricerca scrivere Python Default Interpreter. Troverete una casella dove dovrete incollare il percorso.
7. Per sicurezza salvate con Ctrl + s ed uscite da VSCode.
8. Riaprite VSCode e aprite un file Python. Ora l'autocompletamento dovrebbe funzionare correttamente.
