Creare un file checkout.html che simula la pagina di checkout di un carrello e-commerce.

Requisiti:

Un <h1> "Checkout«
Una sezione "Riepilogo carrello" con una lista di 3 prodotti inventati (es. "Maglietta - 20€", "Scarpe - 50€", "Cappello - 10€")

3 campi <input type="hidden"> con nome/valore: id_prodotto_1, id_prodotto_2, id_prodotto_3

1 campo <input type="hidden" name="totale" value="80"> (il totale in euro)

1 campo <input type="hidden" name="csrf_token" value="xyz123"> (token di sicurezza)

Form con: nome, email, indirizzo, bottone "Conferma ordine"

Obiettivi:

Aprire F12 → Elements: i campi hidden DEVONO essere visibili nel codice HTML ma NON visibili nella pagina
Cliccare "Conferma ordine" e guardare l'URL della pagina ricaricata: i campi hidden devono essere nell'elenco dei parametri inviati
Capire che un utente MALEVOLO potrebbe modificare il campo totale con DevTools (per questo lato server va SEMPRE riverificato)

Estensione opzionale (per chi ha finito prima):

Aggiungere un campo <input type="hidden" name="sconto" value="0"> simulato come se fosse calcolato da JS
Aggiungere un <output> con "Totale: 80€ (gli sconti si applicano al checkout)" come promemoria
Aggiungere un campo "Note" (textarea) opzionale per commenti sull'ordine
