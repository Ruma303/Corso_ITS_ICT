# Esercizio B — la calcolatrice che non si rompe - 60 minuti

1. Il programma chiede due numeri e li divide.
2. Deve reggere: lettere al posto dei numeri, e un denominatore uguale a zero.
3. Il programma deve richiedere i dati se sono sbagliati o lanciano errori

4. Completare Esercizio B "la calcolatrice robusta", aggiungendo un Menù (0=esci, 1=dividi, 2=moltiplica), gestire anche i numeri decimali (nextDouble())
