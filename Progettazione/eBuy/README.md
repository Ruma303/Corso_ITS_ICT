# Struttura del progetto eBuy

>Questo README.md è il punto d'ingresso per capire come muoversi all'interno di questa applicazione che potrebbe risultare complessa.

eBuy è un progetto Full Stack Web con due backend (Python e Java) e un frontend (React + TanStack), insieme all'aggiunta del database PostgreSQL.

Il progetto è diviso principalmente in due cartelle:
- docs: contiene la fase di analisi e di design (Python e Java). 
	- La cartella "prof" con i materiali del professor Mancini, tra cui i requisiti iniziali di tutto il progetto. 
	- Tutte le altre cartelle e altri file sono personalmente creati dall'autore.
- code: a seguito della parte di progettazione, in questa sezione vi sono delle implementazioni in codice del progetto. Essa è divisa in:
	- "frontend" utilizzando React
	- "python" è il backend in Python
	- "java" è il backend in JavaSE
- db: è il database PostgreSQL condiviso tra i due backend e indipendente da qualsiasi ORM

Ogni cartella può contenere ulteriori README.md o file nelle sottocartelle docs/ di supporto. È sempre consigliato leggerle per prima per orientarsi sul progetto.
